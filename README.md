# WindowsHound

This repository is intentionally read-only. The source files (Hound-Integrity.ps1, WindowsHound.ps1, build.ps1) are published for audit and comment only — direct edits to the default branch are disabled.

If you want to propose changes, create an issue describing the change and attach a patch or open a pull request from a fork; repository maintainers will review contributions but will not accept direct edits to the default branch.

See PROTECTION.md for details on how this repository is protected and how to propose changes.
